# Everest NFT Marketplace - NFT Marketplace Application

<img width="2538" height="1439" alt="image" src="https://github.com/user-attachments/assets/9e2adfc7-fd5b-445e-b766-4e9b54a26b52" />

Transformed a static single-page application into an interactive UI with animations, transitions, and carousels, utilizing Axios for dynamic data representation. Employed Git for version control and collaboration.

## Install Packages
```bash
npm i
```

## Start the app

```bash
npm run dev
```
